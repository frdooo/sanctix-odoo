Sanctix Sanctions & Compliance Screening

Automated sanctions, PEP and adverse media screening for Contacts, powered by the Sanctix API.

Screen every Contact in Odoo against global sanctions lists, PEP registries, and adverse media — without leaving the Contacts app. New contacts are screened automatically, existing ones are re-checked on a schedule, and every result is kept as a permanent, append-only audit record.

Key features

🛡️ One-click screening

A "Screen Now" button on every Contact form, with the result and risk level shown right on the record.

⚙️ Automatic & scheduled screening

New contacts are screened on creation; existing ones are re-screened when their name or country changes, and a weekly job catches contacts newly added to a sanctions list.

📦 Batch screening

Select any number of Contacts and screen them in one request via the batch wizard — up to 200 at a time, safely retryable on network failure.

📜 Full audit trail

Every screening call — successful or failed — is logged with its verdict, match count, and the full stored report on demand. A failed API call is always recorded as "Screening Failed", never silently read as "Clear".

🏢 Multi-company safe

API keys are stored per company; screening reports are scoped to the company that ran them.

🔒 Two-tier access control

"Sanctix User" can screen and view history; only "Sanctix Manager" can configure the API key or change automation settings.

Requirements

  • Odoo 17.0 (18.0 compatibility expected, pending install verification).
  • A Sanctix account on a plan with API access enabled (Starter tier and above).

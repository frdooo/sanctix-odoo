Sanctix Sanctions & Compliance Screening

Automated sanctions, PEP and adverse media screening for Contacts, powered by the Sanctix API.

Screen every Contact in Odoo against 11+ global sanctions lists, PEP registries, and adverse media — without leaving the Contacts app. New contacts are screened automatically, existing ones are re-checked on a schedule, and every result is kept as a permanent, append-only audit record with an official-style printable PDF.

Learn more at sanctix.com — plans at sanctix.com/pricing.

Key features

Screening dashboard

Sanctix Compliance → Dashboard: KPI tiles (screenings, clearance rate, blocked, contacts screened), verdict donut, hits-by-source charts, and live quota. Native bar/pivot views break down the full audit table.

Screen a Name (ad-hoc, no contact needed)

Type any person or organization, see the verdict with score ring and top matches. Nothing is saved unless you choose Screen & Save. Tick “Include screening assessment (AI)” for the full screening with AI memo (Growth plan with AI enabled) — still 1 screen.

One-click + automatic + scheduled screening

A “Screen Now” button on every Contact form. New contacts are screened on creation, existing ones re-screened when their name or country changes, and a weekly cron job re-checks contacts not screened in the last 30 days — so a contact added to a sanctions list after you cleared them still gets caught.

Batch screening (up to 200 at a time)

Select any number of Contacts in list view and screen them in one request, retried safely on network failure via an idempotency key so a re-click can’t double-screen.

Document (OCR) screening

On any Contact, Screen Document accepts an invoice, bill of lading or packing list (PDF/JPEG/PNG/WebP, max 10 MB, max 10 pages). Sanctix extracts the parties named on the file and screens each one — one audit row per party, contact rolls up to the worst verdict. Requires a Growth plan or above.

Full audit trail + printable PDF report

Every call — successful or failed — is logged with verdict, match count, and the full stored report on demand. A failed API call is always recorded as “Screening Failed”, never silently read as “Clear”. Each report prints as an official-style PDF (verdict panel, match analysis with signal bars) via Download PDF.

Multi-company safe, two-tier access

API keys stored per company; reports scoped to the company that ran them. “Sanctix User” can screen and view history; only “Sanctix Manager” can configure the API key or change automation settings.

Configuration

  1. In Sanctix, go to Settings → API Keys and create a key (admin role, plan with API access — Starter tier and above).
  2. In Odoo, go to Settings → Sanctix Compliance (visible to Sanctix Managers).
  3. Paste the API key, click Save, then Test Connection to confirm and see remaining quota.
  4. Adjust the automatic-screening toggles (on create, on name/country change, scheduled re-screening — all default on).

Requirements

  • Odoo 18.0 (this branch — the version prefix must match the series).
  • A Sanctix account with API access enabled on your plan (Starter tier and above). Free/Trial plans cannot issue API keys.
  • The requests Python package (bundled with every standard Odoo install).
